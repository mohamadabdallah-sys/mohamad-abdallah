# القوى وقوى العشرة — الصف السابع (شعبة نور)

مواد الحصّة حسب التحضير (50 دقيقة: تمهيد 5 د + استكشاف 30 د + تفسير 10 د + تطبيق 5 د).

- `عرض-القوى-وقوى-العشرة.pptx`: عرض من 24 شريحة يتبع مراحل الحصّة، مع ملاحظات للمعلّم في كل شريحة (التوقيت وما يقال).
- `بطاقات-القوى-وقوى-العشرة.pdf`: بطاقات للطباعة على A4:
  1. النشاط 1 – طيّ الورقة (جدول للمجموعة)
  2. النشاط 2 – من الكتابة المفكّكة إلى القاعدة
  3. النشاط 3 – لغز الأُس صفر
  4. بطاقة الشرح «القوى وقواعدها»
  5. تحدّي المتميّزين (القمر) + «انتبه! أخطاء شائعة» (نصف صفحة لكلّ منهما)
  6. الواجب البيتي (نسختان في الصفحة)
  7. بطاقات المصطلحات وأدوار المجموعة (للقصّ)
  8. مفتاح الإجابات للمعلّم

## البناء
```
npm install && node make_ppt.js <path>/apply_theme.js   # العرض
python3 make_cards.py                                   # البطاقات (Chromium عبر Playwright، وخطوط ../../grade7-book/fonts)
```
